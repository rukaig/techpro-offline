Understanding Computer Hardware and Software

[[IMG:image10.png]]
Have you ever opened a computer program to prepare a document, browse the internet, or create a presentation? These tasks are possible because a computer's physical parts and software work together.

The physical components you can see and touch are called hardware. These include the keyboard, monitor, motherboard, processor, memory, and storage drive. Meanwhile, software refers to the programs and instructions that tell the computer what to do.

A computer cannot function properly using hardware alone. It needs system software to manage its components and application software to help users perform specific tasks. Understanding how hardware and software work together is important before learning how to disassemble and assemble a computer system.

| [[IMG:image11.png]] | What is It |

|---|---|

The Computer System

A computer system consists of hardware and software that work together to receive data, process it, store information, and produce output.

For example, when you type a school report, the keyboard accepts your input, the processor handles the instructions, memory temporarily holds the working data, the operating system manages the computer’s resources, and the word processor lets you create and edit the document.

In this process, each hardware and software component performs a particular function. If one important component is missing, incorrectly installed, or incompatible, the computer may not operate properly.

Types of Computers

Computers are designed in different forms depending on the tasks they need to perform. Some computers are intended for individual users, while others provide services to many users or handle large amounts of information.

Desktop Computer

[[IMG:image12.png]]
A desktop computer is designed for use in a fixed location. It commonly consists of a system unit, monitor, keyboard, and mouse.

Desktop computers are often used in computer laboratories, offices, homes, and service centers. Their internal components are generally accessible, making them suitable for hardware disassembly, assembly, repair, maintenance, and upgrading.

[[IMG:image13.png]]
Laptop Computer

A laptop computer is a portable personal computer. The screen, keyboard, touchpad, battery, processor, memory, and storage device are contained in one compact unit.

A laptop can perform many of the same tasks as a desktop computer. However, its compact construction may make its internal components more difficult to access, repair, or replace.

Tablet

[[IMG:image14.png]]
A tablet is a portable computer that mainly uses a touchscreen for input. People commonly use it to view learning materials, browse the internet, communicate, and run mobile applications.

Unlike a desktop computer, most tablet components are integrated into a thin enclosure and are not intended for regular user upgrades.

[[IMG:image15.png]]
Server

A server is a computer that provides services, information, or shared resources to other computers on a network. It may store user files, host applications, manage accounts, or provide network services.

Servers are usually designed to operate continuously and support several users or devices.

Parts of a Computer

Computer hardware can be classified as external or internal.

External Hardware

External hardware refers to the devices attached to or used outside the system unit.

Keyboard

The keyboard is an input device used to enter letters, numbers, symbols, and commands into the computer.

Mouse

The mouse is a pointing device used to move the pointer, select items, open files, and interact with objects displayed on the screen.

Monitor

The monitor is an output device that displays text, images, videos, and other information produced by the computer.

Speakers

Speakers are output devices that produce sound from the computer.

Printer

A printer is an output device that produces a physical copy of a document or image.

Internal Hardware

Internal hardware refers to the components installed inside the computer case.

[[IMG:image16.png]]
Motherboard

The motherboard is the main circuit board of a computer. It provides connections for the processor, memory, storage devices, expansion cards, power supply, and other components.

The motherboard allows the different hardware components to communicate with one another.

[[IMG:image17.png]]
Central Processing Unit

The Central Processing Unit, commonly called the CPU or processor, executes instructions and performs calculations. The CPU processes data and controls many of the computer’s operations.

The processor must be compatible with the motherboard's CPU socket and chipset.

[[IMG:image18.png]]
Random-Access Memory

Random-Access Memory, or RAM, temporarily stores data and instructions the processor is currently using. RAM clears when you turn off the computer.

A computer with sufficient RAM can operate several programs more efficiently.

Storage Device

[[IMG:image19.png]]
A storage device keeps files, programs, and the operating system even when the computer is turned off.

Common computer storage devices include:

- hard disk drives;

- [[IMG:image20.png]]
solid-state drives; and

- optical drives.

[[IMG:image21.png]]
Power Supply Unit

The Power Supply Unit, or PSU, converts electricity from the outlet into the electrical power required by the internal computer components.

The power supply must provide the appropriate connectors and sufficient power for the installed hardware.

[[IMG:image22.png]]
Cooling System

The cooling system helps control the operating temperature of computer components. It may include heat sinks, case fans, and a processor fan.

Improper cooling may cause overheating, system instability, or damage to computer components.

[[IMG:image23.png]]
Expansion Card

An expansion card adds or improves a computer function. Examples include graphics cards, sound cards, and network interface cards.

Expansion cards are installed in compatible expansion slots on the motherboard.

Computer Software

Software consists of programs and instructions that direct the computer to perform tasks. Software is commonly divided into system software and application software.

What Is System Software?

System software manages the computer’s hardware and basic operations. It connects computer hardware and the programs users run.

Examples of system software include operating systems, device drivers, utility programs, and firmware.

Operating System

[[IMG:image24.png]]
An operating system manages the computer's major resources, including the processor, memory, storage devices, input devices, and output devices.

The operating system also provides an interface that lets users open files, run programs, manage folders, and change computer settings.

[[IMG:image25.png]]
Device Driver

A device driver allows the operating system to communicate with a specific hardware device.

For example, a printer driver helps the operating system send the correct instructions to a printer. Without an appropriate driver, the device may not be recognized or may not function correctly.

Utility Software

Utility software helps maintain, protect, configure, or improve the computer system.

[[IMG:image26.png]]
Examples include:

- antivirus utilities;

- storage management tools;

- backup utilities;

- file compression tools; and

- system diagnostic programs.

Firmware

[[IMG:image27.png]]
Firmware is software stored in a hardware device. It provides the basic instructions required to control or start the device.

The Basic Input/Output System, or BIOS, and the Unified Extensible Firmware Interface, or UEFI, are examples of firmware used during computer startup.

What Is Application Software?

Application software helps users accomplish tasks. Software operates with the assistance of the operating system.

Examples include:

- [[IMG:image28.png]]
word-processing software for creating documents;

- spreadsheet software for organizing and calculating data;

- presentation software for creating visual presentations;

- web browsers for accessing websites;

- graphics software for creating and editing images;

- multimedia software for playing or editing audio and video; and

- educational applications for completing learning activities.

System Software and Application Software

System software and application software perform different but connected functions.

| System Software | Application Software |

|---|---|

| Manages hardware and basic computer operations | Helps the user perform a specific task |

| Commonly operates in the background | Usually opened and controlled by the user |

| Provides a platform for other programs | Requires system software to operate |

| Includes operating systems and drivers | Includes word processors and web browsers |

For example, when a learner creates a report, the word processor is the application software. The word processor uses the operating system to access the keyboard, monitor, memory, and storage device.

Computer Disassembly

Computer disassembly is the systematic removal of computer components from the system unit. It may be performed for cleaning, inspection, repair, replacement, upgrading, or troubleshooting.

Disassembly should not be performed by removing components randomly. A technician must observe safety precautions, document connections, organize removed parts, and follow the correct sequence.

Preparing for Computer Disassembly

Before disassembling a computer, perform the following preparations:

- Shut down the computer properly.

- Disconnect the power cable from the electrical outlet.

- Disconnect the peripheral devices.

- Remove jewelry and other conductive accessories.

- Prepare the required tools and parts containers.

- Wear an antistatic wrist strap or apply appropriate electrostatic discharge precautions.

- Document or take pictures of existing cable connections.

- Prepare labels for cables, screws, and components.

These procedures reduce the risk of electric shock, lost parts, incorrect connections, and damage to electronic components.

Basic Computer Disassembly Procedure

The exact procedure may vary depending on the computer case and installed components. Always check the manufacturer’s instructions when available.

A common computer disassembly sequence is as follows:

Step 1: Shut Down and Disconnect the Computer

Shut down the operating system properly. Remove the power cable and disconnect all peripheral devices.

Step 2: Prepare the Work Area

Use a clean, well-lit, dry, and organized work area. Prepare the tools, antistatic equipment, labels, and parts containers.

Step 3: Document the Connections

Take clear pictures, draw a connection diagram, or label the cables before removing them. This information will guide you during reassembly.

Step 4: Open the Computer Case

Remove the screws or release the fasteners that secure the side panel. Place the screws in a labeled container.

Step 5: Disconnect Internal Cables

Carefully disconnect the power and data cables. Hold each connector instead of pulling directly on the wires.

Step 6: Remove Expansion Cards

Release each card from its expansion slot and hold the card by its edges. Avoid touching the gold contacts or electronic components.

Step 7: Remove Storage Devices

Disconnect the storage device cables. Release the mounting screws or brackets before removing each drive.

Step 8: Remove the Memory Modules

Open the retaining clips and lift the memory module by its edges. Do not touch its contact pins.

Step 9: Remove the Cooling System and Processor

Disconnect the cooling fan, release the heat sink, and remove the processor carefully. This procedure requires special care because processor socket pins and contact points may be easily damaged.

Step 10: Remove the Power Supply and Motherboard

Support each component while removing its mounting screws. Store the screws and parts in properly labeled containers.

Computer Assembly

Computer assembly is the proper installation and connection of the components that make up a functional computer system.

In general, computer assembly follows the reverse order of disassembly. However, the technician must still follow the manufacturer’s instructions and confirm component compatibility.

Basic Computer Assembly Procedure

Step 1: Prepare and Inspect the Components

Check the components for physical damage. Confirm that the processor, motherboard, memory, storage device, power supply, and other components are compatible.

Step 2: Install the Processor

Align the processor correctly with the motherboard socket. Gently place the processor into the socket and secure it with the locking mechanism.

Never force the processor into the socket.

Step 3: Install the Cooling System

Apply thermal interface material when required. Install the heat sink and cooling fan securely, then connect the fan cable to the correct motherboard header.

Step 4: Install the Memory Modules

Align the memory module with the slot. Press it evenly until the retaining clips lock into place.

Step 5: Install the Motherboard

Position the motherboard over the correct case standoffs. Secure the motherboard with the appropriate screws, but don't overtighten them.

Step 6: Install the Power Supply

Position and secure the power supply. Make sure its ventilation openings are not blocked.

Step 7: Install the Storage Devices

Secure the storage devices inside the appropriate drive bays or mounting locations.

Step 8: Install the Expansion Cards

Insert each expansion card into the correct slot and secure the card to the computer case.

Step 9: Connect the Cables

Connect the power cables, data cables, front-panel connectors, cooling fans, and peripheral cables. Use the documentation prepared during disassembly as a guide.

Step 10: Inspect the Assembly

Before connecting the computer to electricity, check that:

- [[IMG:image29.png]]
all components are correctly seated;

- all cables are connected securely;

- no loose screw is left inside the case;

- no cable is blocking a cooling fan;

- all required components are installed; and

- the computer case is properly closed.

Let’s Remember

A computer system is composed of hardware and software that work together to process data and perform tasks.

Hardware refers to the physical parts of a computer you can see and touch. These include the motherboard, processor, RAM, storage drive, power supply unit, monitor, keyboard, and mouse.

Software refers to the programs and instructions that direct the computer’s operations. Software may be classified into:

- System software, which manages computer hardware and basic operations; and

- Application software, which helps users perform specific tasks such as creating documents, browsing websites, and preparing presentations.

How a Computer System Works

Hardware + System Software + Application Software = Functional Computer System

Each part has an important role:

| Component | Main Function |

|---|---|

| Processor | Executes instructions and processes data |

| Motherboard | Connects and supports internal components |

| RAM | Temporarily stores active data and instructions |

| Storage Drive | Stores files, programs, and the operating system |

| Power Supply Unit | Provides electrical power to the components |

| Operating System | Manages hardware and other software |

| Application Software | Helps the user complete specific tasks |

Safe Disassembly and Assembly

Before disassembling a computer:

- Shut down the computer properly.

- Disconnect the computer from the power source.

- Prepare the necessary tools and a clean work area.

- Observe electrostatic discharge precautions.

- Document and label the cable connections.

- Organize the removed components and screws.

During assembly, install each compatible component in the correct position and reconnect the cables securely. Before turning on the computer, inspect the completed assembly to ensure that no component is loose, no connection is missing, and no cable is blocking a cooling fan.
